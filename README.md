# The Daily Atlas
A newspaper-style representation of world news for Thursday, 19 November 2026.

This repository generates a 1024x1024 PNG image summing up the world news of that day.

## How to build and run
1. Set up the virtual environment:
   `python3 -m venv .venv && .venv/bin/pip install pillow numpy`
2. Generate the page:
   `.venv/bin/python draw.py`
3. Deploy the result:
   `.venv/bin/python main.py`
